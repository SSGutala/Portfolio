# **App Name**: Srivatsav Portfolio

## Core Features:

- Smooth Scrolling Navigation: Enable smooth scrolling to different sections (Consulting, Ventures, Product, UI/UX) using anchor links in the navigation bar.
- Animated Section Reveal: Fade and slide in page sections upon scrolling to create a visually engaging experience.
- Venture Concept Showcase: Display venture concepts in a horizontally scrolling list (on mobile) with logos, thesis, and stage indicators.
- Connect Modal: Implement a modal contact form (Name, Email, Message, Topic) with mailto: fallback for initial functionality.
- UI/UX Mockup Carousel: Display UI/UX mockups in an image grid or carousel format with descriptive captions.
- Active Navigation Link Highlighting: Automatically highlight the active navigation link based on the section currently in view.
- Resume display and downloader: Links to download a PDF representation of the user's resume

## Style Guidelines:

- Background color: Black (#000000) to establish a modern and sleek dark theme.
- Primary color: Soft gray (#D1D1D1) for text to provide good contrast against the black background, ensuring readability.
- Accent color: Slightly brighter gray (#1A1A1A) for borders and secondary elements, creating subtle visual separation.
- Font: 'Inter' (sans-serif) for headings and body text. Note: currently only Google Fonts are supported.
- Use a max-w-6xl container with horizontal padding of px-6 (md:px-8) to maintain content consistency and readability across devices.
- Implement a hover underline animation on navigation links and subtle lift+gradient animations on cards to provide engaging micro-interactions.
- Ensure smooth scrolling behavior for navigation links and subtle fade/slide animations for sections on scroll to enhance user experience.
